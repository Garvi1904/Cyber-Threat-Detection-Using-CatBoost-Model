# Cyber-Threat-Detection-Using-CatBoost-Model-Research-paper-
This repository contains the research paper and code for "Cyber Threat Detection Using CatBoost ML Model" - a machine learning approach for detecting cyber threats in IoT and Cyber-Physical Systems.
# Research Paper
The paper presents an Intrusion Detection System using CatBoost that achieves:

1.98.6% accuracy in binary classification

2.Real-time performance with fast inference

3.Interpretable results using SHAP analysis

4.Superior performance over traditional ML models
